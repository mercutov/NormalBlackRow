# Normal Black Row

Кадрирует картинку в фиксированную высоту **1440** и кладёт тонкую чёрную полоску внутрь кадра.

Готовые ширины: **845**, **1280**, **1690**. Четвёртый вариант — своя ширина от 600 до 2000 при той же высоте 1440. Полоска по умолчанию слева, **6** пикселей. Файл получается ровно выбранного размера: полоска не добавляется сверх него.

В окне картинку тянут мышью, колёсико меняет масштаб, двойной щелчок вписывает кадр. Серая черта показывает границу полоски и в файл не попадает.

## Установка

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/mercutov/NormalBlackRow/master/install.ps1 | iex
```

Скрипт спросит папку (Enter — `%USERPROFILE%\NormalBlackRow`) и скачает программу вместе с моделью. Путь лучше без кириллицы.

Дальше — `Normal Black Row.bat` или перетащите на него картинку.

При запуске программа сравнивает файл `VERSION` с версией на GitHub. Если на сайте новее, предлагает обновиться и перезапускается. Повторная установка той же командой тоже обновляет папку.

## Если картинка меньше кадра

Пока кадр не крупнее исходных пикселей, картинка только обрезается.

Если вы приблизили фрагмент или исходник сам меньше кадра, обычное увеличение (Lanczos) мылит. В репозитории уже лежит **Real-ESRGAN** (`realesrgan-x4plus`, портативная сборка [xinntao/Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) v0.2.5.0, лицензия BSD): выбранный кусок увеличивается в 4 раза на видеокарте через Vulkan, затем приводится к точному размеру кадра. Если модели в копии нет, окно может скачать её отдельно. Если она не запустилась, можно сохранить обычным увеличением.

Галочка «Нейросеть, если кадр крупнее пикселей» включает это только когда увеличение действительно нужно.

## Командная строка без окна

Только полоска, без кадрирования. Холст при этом увеличивается на ширину полоски.

```powershell
py -3 normal_black_row.py photo.jpg
py -3 normal_black_row.py photo.jpg --side right --width 8
py -3 normal_black_row.py photo.jpg -o photo_bar.jpg
```

Стороны: `left`, `right`, `top`, `bottom` (или `лево`, `право`, `верх`, `низ`).
