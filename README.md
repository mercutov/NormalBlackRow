# Normal Black Row

Кадрирует картинку в один из трёх размеров и кладёт тонкую чёрную полоску внутрь кадра.

Размеры: **845×1440**, **1280×1440**, **1690×1440**. Полоска по умолчанию слева, **6** пикселей. Файл получается ровно выбранного размера: полоска не добавляется сверх него.

В окне картинку тянут мышью, колёсико меняет масштаб, двойной щелчок вписывает кадр. Серая черта показывает границу полоски и в файл не попадает.

## Запуск

Дважды щёлкните `Normal Black Row.bat` или перетащите на него картинку.

```powershell
py -3 -m pip install -r requirements.txt
py -3 app_gui.py photo.jpg
```

## Если картинка меньше кадра

Пока кадр не крупнее исходных пикселей, картинка только обрезается.

Если вы приблизили фрагмент или исходник сам меньше кадра, обычное увеличение (Lanczos) мылит. Для этого есть **Real-ESRGAN** (модель `realesrgan-x4plus`, видеокарта через Vulkan): выбранный кусок увеличивается в 4 раза, затем приводится к точному размеру кадра. Кнопка в окне скачивает портативную сборку, около 43 МБ, в папку `tools/`. В git её нет. Если модели нет или она не запустилась, можно сохранить обычным увеличением.

Галочка «Нейросеть, если кадр крупнее пикселей» включает это только когда увеличение действительно нужно.

## Командная строка без окна

Только полоска, без кадрирования. Холст при этом увеличивается на ширину полоски.

```powershell
py -3 normal_black_row.py photo.jpg
py -3 normal_black_row.py photo.jpg --side right --width 8
py -3 normal_black_row.py photo.jpg -o photo_bar.jpg
```

Стороны: `left`, `right`, `top`, `bottom` (или `лево`, `право`, `верх`, `низ`).
